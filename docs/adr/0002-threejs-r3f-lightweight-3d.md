# ADR 0002: Three.js / React Three Fiberで軽めの3D表現にする

## Status

Accepted

## Context

このアプリでは、折り紙がパタンと折れる立体感が重要である。一方で、スマホ優先でなめらかに動く必要があり、本物の紙の物理シミュレーションまでは不要である。

## Decision

Three.js / React Three Fiberを使い、軽めの3D表現で折る・ひらくアニメーションを実装する。紙は硬い板のように折り線を軸に回転させ、しなりは扱わない。

## Consequences

- 3Dの折り動作を表現しやすい。
- SVGやCanvas 2Dより立体感を出しやすい。
- 物理シミュレーションより軽く制御しやすい。
- 3D表示と2D幾何モデルの対応を丁寧に管理する必要がある。
