# UI and Visual Design

## 基本方針

- 子ども向け画面は完全に文字なし。
- 画面の主役は紙。
- メイン操作は画面下中央。
- 補助操作は右上。
- 押せないボタンは表示しない。
- 紙・ボタン・穴が見やすいことを優先する。

## 画面

- スマホ縦向き固定を優先する。
- タブレットでは余白を広げ、紙とボタンを大きく扱う。
- 背景は白〜薄いグレー。
- 紙は画面中央に大きく表示する。
- 紙にはやわらかい落ち影をつける。

## 紙

- 形は正方形のみ。
- 初期色は水色。
- 選択可能な色は赤、水色、黄、緑、ピンク。
- 裏面は表より少し薄い同系色。
- 紙の外周に見た目上の薄い厚みを出す。
- 切り抜き穴の断面厚みは表現しない。
- 折った紙の重なりは、端や影でうっすら層が見えるようにする。
- 折り終わった紙はぴったり重ね、見た目のための意図的なズレは入れない。

## 穴

- 穴は白く表示する。
- 表面でも裏面でも白い穴として見せる。
- 折られた紙の上では、タップした場所だけに穴があるように見せる。
- 開く途中で、折りを戻すたびに鏡写しの穴が増える。

## ボタン

- メイン操作ボタンは白い丸ボタン＋濃いグレーのアイコン。
- 図形ボタンも白い丸ボタン＋濃いグレーの図形アイコン。
- 図形ボタンの並び順は、丸、三角、四角、ハート、星。
- 右上の補助アイコンは親向けに少し小さめ。

## アイコン

- 折るアイコンは、紙が半分に折れている絵。
- ひらくアイコンは、折られた紙が開いている絵。
- 色パレットアイコンは虹色の丸。
- 音ON/OFFアイコンはスピーカー。
- 新しい紙アイコンは、新しい紙が出てくる絵。
