# Product Requirements

## 目的

「ちょきちょきおりがみ」は、5歳児が説明文を読まずに、折り紙を折り、図形で切り抜き、ひらいたときに模様が増える驚きを体験するアプリである。

## 対象ユーザー

- 主ユーザーは5歳児。
- 文字は読めない前提。
- 保護者は起動、ホーム画面追加、音OFFなどを補助する可能性がある。

## 体験の中心

- 正解・不正解はない。
- 教材クイズではなく、自由に遊ぶ。
- 「折る → 切る → ひらく → 完成を見る → 新しい紙でまた遊ぶ」の1サイクルを気持ちよく回す。

## 必須要件

- 子ども向け画面は完全に文字なし。
- スマホ縦向き優先。
- タブレットにも対応。
- 紙は正方形のみ。
- 折り回数は最大3回。
- 折り方は固定順。
- 切り抜き図形は丸、三角、四角、ハート、星。
- 図形サイズは固定。
- 1作品あたりの切り抜きは最大10個程度。
- 10個を超えたら最古の切り抜きがふわっと消え、新しい切り抜きが入る。
- 一度切ったら追加の折りはできない。
- 切った後も図形を変えて追加で切れる。
- ひらく操作は、1個以上切った後に表示する。
- ひらくボタン1回で最後まで展開する。
- 完成後は紙をタップしても反応しない。
- 次に進むには新しい紙ボタンを押す。

## 非対象

- 正解判定。
- スコア。
- 自由線によるハサミ切り。
- 複雑な折り方選択。
- 保存・共有。
- 物理的にリアルな紙のしなり。
- アプリ内の親向け説明文。
