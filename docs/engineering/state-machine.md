# State Machine

## 状態一覧

### idle

初期状態。紙は開いている。折るボタンだけが主操作として表示される。

### folding

折るアニメーション中。操作は受け付けない。

### folded_uncut

1回以上折られており、まだ切っていない状態。折るボタンと図形ボタンが表示される。

### cuttable

1個以上切り抜きがある状態。図形ボタンとひらくボタンが表示される。折るボタンは表示しない。

### unfolding

ひらくアニメーション中。操作は受け付けない。

### completed

完成作品を表示している状態。新しい紙ボタンだけを表示する。紙タップには反応しない。

### color_palette_open

色パレットを開いている状態。通常の操作ボタンは隠れ、下に色ボタンだけを表示する。

### resetting

新しい紙への切り替え中。完成作品が小さく消え、新しい紙が出る。操作は受け付けない。

## 主な遷移

- idle → folding: 折るボタン。
- folding → folded_uncut: 折りアニメーション完了。
- folded_uncut → folding: 追加の折るボタン。ただし最大3回まで。
- folded_uncut → cuttable: 紙をタップして最初の切り抜き。
- cuttable → cuttable: 図形選択または追加切り抜き。
- cuttable → unfolding: ひらくボタン。
- unfolding → completed: 展開完了。
- completed → resetting: 新しい紙ボタン。
- resetting → idle: 新しい紙表示完了。
- 任意の通常状態 → color_palette_open: 右上の色アイコン。
- color_palette_open → 元の状態: 色選択または紙周辺タップ。

## 完成後のふるまい

- completed では折る、ひらく、図形選択は表示しない。
- completed では紙タップは無視する。
- resetting 中も通常の紙タップや操作は受け付けない。

## 切り抜き数の制御

- 切り抜きは最大10個程度。
- 上限を超える場合、最古の切り抜きをふわっと消してから新しい切り抜きを追加する。

## 初回誘導フラグ

- 折るボタンの初回誘導は、最初に折るボタンを押した時点で終了する。
- 紙タップ誘導は、最初に切り抜きが成功した時点で終了する。
- 新しい紙にしても、終了済みの誘導は再表示しない。
