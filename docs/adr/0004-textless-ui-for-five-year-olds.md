# ADR 0004: 子ども向け画面を完全に文字なしにする

## Status

Accepted

## Context

主ユーザーは5歳児であり、文字を読めない前提である。説明文やラベルに頼ると、子どもが保護者なしで遊びにくくなる。

## Decision

子ども向け画面は完全に文字なしにする。操作はアイコン、色、音、アニメーションによって伝える。親向け説明はアプリ内に置かず、必要ならアプリ外に置く。

## Consequences

- 5歳児が直感的に遊びやすい。
- UIアイコンとアニメーションの分かりやすさが重要になる。
- アプリ内で詳細な説明はできない。
- 初回誘導はボタンの動きや薄い図形プレビューで補う。
