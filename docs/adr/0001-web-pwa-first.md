# ADR 0001: Webアプリ/PWAを先に作る

## Status

Accepted

## Context

対象は5歳児であり、スマホやタブレットで手軽に遊べる必要がある。アプリはサーバー通信を必要とせず、折る・切る・ひらく体験は端末内で完結できる。

## Decision

最初の実装はWebアプリとして作り、ホーム画面に追加できるPWAにする。オフラインでも遊べるようにする。

## Consequences

- URLからすぐ試せる。
- ホーム画面に置けばアプリのように起動できる。
- オフライン対応がしやすい。
- ネイティブアプリ固有の機能は最初の対象外になる。
