# User Flow

## 初回起動

1. アプリを開く。
2. 白〜薄いグレー背景の中央に、水色の正方形の紙が表示される。
3. 画面下中央に大きな折るアイコンが表示される。
4. 右上に小さな虹色丸アイコンとスピーカーアイコンが表示される。
5. 折るボタンだけが、初回のみゆっくり大きくなったり戻ったりする。

## 折る

1. 子どもが折るボタンを押す。
2. ボタン類は一時的に消える。
3. 折り線が白っぽい細い光の線で一瞬強調される。
4. 紙の片側が折り線を軸に3Dでパタンと回転する。
5. やわらかい「ぱたん」音が鳴る。
6. 折り終わったら紙がふわっと中央に移動する。
7. 次に使えるボタンが表示される。

## 折った後

1. 1回以上折ったら、図形ボタンが下に横並びで表示される。
2. 図形ボタンは丸、三角、四角、ハート、星の順。
3. 初期選択は丸。
4. 最初の1回だけ、紙の中央あたりに選択中の図形の薄いプレビューが数回ふわっと出る。

## 切る

1. 子どもが紙をタップする。
2. タップした場所に、選択中の図形の白い穴がすぐ開く。
3. 短い「ちょきん」または「ぽん」系の音が鳴る。
4. 小さくキラッとする。
5. 紙が一瞬だけ控えめにぷるっと揺れる。
6. 1個以上切ったら、折るボタンは消え、ひらくボタンが表示される。
7. 図形ボタンは残り、追加で切れる。

## ひらく

1. 子どもがひらくボタンを押す。
2. ボタン類は消える。
3. 紙は折り順と逆順に段階的に開く。
4. 開くたびに切り抜きが増えて見える。
5. 各段階で0.2〜0.4秒ほど止まり、小さく「ぱらっ」系の音が鳴る。
6. 最後まで開いたら正面から平らに表示される。
7. 紙がふわっと少し拡大する。
8. 紙の外側だけに控えめなキラキラ演出が出る。
9. 完成音が鳴る。
10. 画面下中央に新しい紙ボタンが表示される。

## 新しい紙

1. 子どもが新しい紙ボタンを押す。
2. 完成作品がふわっと小さくなって消える。
3. 現在の紙色を引き継いだ新しい紙がぽんっと出る。
4. 小さく「ぽん」音が鳴る。
5. 初期状態に戻る。
