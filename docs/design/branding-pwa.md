# Branding and PWA

## アプリ名

アプリ名は「ちょきちょきおりがみ」。

子どもが言いやすく、保護者にも折り紙を切って遊ぶアプリであることが伝わる名前にする。

## PWA方針

- Webアプリとして作る。
- ホーム画面に追加できるPWAにする。
- 一度開いたらオフラインでも遊べるようにする。
- 起動後、ローディング画面は出さず、すぐ遊べる状態を目指す。

## ホーム画面アイコン

- やさしい・かわいい系。
- 白〜薄いグレー背景。
- 水色ベースの少し折られた紙。
- 白い切り抜き穴として、丸、ハート、星を入れる。
- 丸みのある雰囲気にする。
- アプリ本体の初期色である水色と印象をそろえる。

## アプリ内テキスト

- 子ども向け画面には文字を出さない。
- 親向け説明はアプリ内には置かない。
- 説明が必要な場合は、ストア説明、LP、保護者向けページなどアプリ外に置く。
