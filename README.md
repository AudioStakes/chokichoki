# ちょきちょきおりがみ

5歳児が文字を読まずに、折る・切る・ひらく体験を楽しむ折り紙展開Webアプリです。

子どもは画面中央の折り紙を、下部の大きなアイコンで折り、図形ボタンを選んで紙をタップし、最後にひらくことで、切り抜きが対称に増えていく様子を見られます。

## いま動かす場所

このリポジトリの本体は、ルート直下の Vite + React 実装です。

- 起動入口: `src/main.tsx`
- アプリ本体: `src/App.tsx`
- 状態機械: `src/shell.ts`
- 旧プロトタイプ: `prototype/chatgpt_5.5/`

`prototype/chatgpt_5.5/` は試作の記録として残してあり、現在の本実装はルートのファイルを見てください。

## コンセプト

- 対象は5歳児。
- 子ども向け画面は完全に文字なし。
- 正解・不正解のない自由あそび。
- 折る、切る、ひらく、完成を見る、もう一度遊ぶ、の1サイクルを気持ちよく体験する。
- 見た目は軽めの3D、内部計算は正確な2D幾何モデルで管理する。
- スマホ縦向き優先、タブレットにも対応する。
- PWAとしてホーム画面追加とオフライン利用に対応する。

## 体験フロー

1. 起動すると、水色の正方形の紙が中央に表示される。
2. 下中央の折るアイコンを押す。
3. 紙が固定順で最大3回まで折れる。
4. 1回以上折ると、図形ボタンが表示される。
5. 図形を選び、紙をタップすると白い穴が開く。
6. 1個以上切ると、ひらくアイコンが表示される。
7. ひらくアイコンを押すと、紙が段階的に開き、切り抜きが鏡写しで増える。
8. 完成時は紙を正面から少し拡大して見せ、紙の外側に控えめなキラキラを出す。
9. 新しい紙アイコンを押すと、同じ色の新しい紙でまた遊べる。

## 主要仕様

### ユーザー体験

- 文字は使わず、アイコン・音・アニメーションで伝える。
- 最初の1回だけ、折るボタンをゆっくり大きくして誘導する。
- 最初の切り操作だけ、紙の中央に選択中図形の薄いプレビューを数回表示する。
- アニメーション中はボタンを消し、操作を受け付けない。

### 折る

- 折るボタンは下中央に大きく表示する。
- 折る方向は固定。
- 最大3回まで折れる。
- 固定折り順は次の通り。
  1. 左半分を右へ折る
  2. 下半分を上へ折る
  3. 左半分を右へ折る
- 折る直前に白っぽい細い光の折り線を一瞬表示する。
- 折るアニメーションは、折り線を軸にしっかり3D回転する。
- 折り終わった紙は、ふわっと中央に移動する。

### 切る

- 切れるのは1回以上折ったあと。
- 一度切ったら、追加で折ることはできない。
- 切ったあとも、図形を変えて最大10個まで追加で切れる。
- 10個を超えたら、最も古い穴がふわっと消え、新しい穴が入る。
- 切り抜き図形は、丸、三角、四角、ハート、星。
- 図形サイズは固定。
- 図形は回転しない。
- タップした瞬間に白い穴が開く。
- 紙の少し外側のタップも受け付け、自然に紙の中へ補正する。
- 図形が紙の端からはみ出して切れてもよい。
- 見た目ではタップした場所に穴が1つ見えるが、内部では重なっている紙全部を切る。

### ひらく

- ひらくボタンは、1個以上切ったあとに下中央へ表示する。
- ひらくボタンを1回押すと、最後まで全部ひらく。
- 展開は段階的に行い、折りを戻すたびに切り抜きが増えて見える。
- 各段階で0.2〜0.4秒ほど止める。
- 完成時は正面から平らに見せ、少し拡大する。
- 完成後、紙タップには反応しない。

### 見た目

- 背景は白〜薄いグレー。
- 紙は画面中央に大きく表示する。
- 紙にはやわらかい落ち影をつける。
- 紙の外周には見た目だけ少し厚みを持たせる。
- 穴の断面は表現しない。
- 折った紙の重なりは、端や影でうっすら層が見えるようにする。
- 折り目線は完成作品にも薄く残す。
- 表面は選択色、裏面は表より少し薄い同系色。
- 穴は表面・裏面とも白い穴として表示する。

### 色

- 初期紙色は水色。
- 選べる色は、赤、水色、黄、緑、ピンク。
- 右上の虹色丸アイコンから色パレットを開く。
- 色パレット中は、下部に5色の大きな丸ボタンだけを表示する。
- 色を変えても、切り抜きや完成模様は残る。
- 色変更は0.2〜0.4秒でふわっと切り替わる。

### 音

- 初期状態は音ON。
- 右上の小さなスピーカーアイコンでON/OFFできる。
- 折る、切る、ひらく、完成、図形選択、色変更、新しい紙に短い効果音を使う。
- バイブレーションは使わない。

## 技術方針

- Webアプリとして実装する。
- Reactを使う。
- 3D表示にはThree.js / React Three Fiberを使う。
- 見た目は3D、正確な計算は2Dで行う。
- 切り抜き位置、折り履歴、展開結果は元の正方形の2D座標系を基準に管理する。
- タップ位置の取得にはRaycastingを使う。
- PWAとして、ホーム画面追加とオフライン利用に対応する。

## 実装時の重要ルール

- 5歳児が読む前提の文字UIを追加しない。
- 3D上の見た目を正確性の唯一の情報源にしない。
- 折る・切る・ひらくの正確性は、2D幾何モデルを基準にする。
- 切るときは、見えている一番上だけではなく、重なっている紙全部を切る。
- 折り終わりの見た目を意図的にずらさない。
- 操作可能なボタンだけを表示する。
- アニメーション中は状態を変えない。

## アプリ名とPWAアイコン

アプリ名は「ちょきちょきおりがみ」。

PWAアイコンは、白〜薄いグレー背景に、水色ベースの少し折られたかわいい折り紙を置き、白い穴で丸・ハート・星を表現する。
