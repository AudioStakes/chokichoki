# ADR 0005: 折り方を固定順にする

## Status

Accepted

## Context

子どもが折る方向を選ぶ設計も可能だが、5歳児には選択肢が多いと迷いやすい。毎回同じように動くことは安心感につながる。また、切り抜き位置と展開結果の正確性を担保しやすい。

## Decision

折るボタンは1つだけにし、折り順は固定する。最大3回まで、順番は「左半分を右へ」「下半分を上へ」「左半分を右へ」とする。

## Consequences

- 子どもが折る方向を選ばなくてよい。
- 毎回同じ結果になり、遊びが安定する。
- 折り・切り・展開ロジックを作り込みやすい。
- 自由な折り方は最初の版では扱わない。
