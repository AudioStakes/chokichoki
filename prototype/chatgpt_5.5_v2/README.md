# Origami Fold/Cut Prototype

`chokichoki` の `prototype` 配下に追加するための、React Three Fiber 製の折り紙アニメーション試作です。

## ここまでの判断メモ

- 見た目よりも、折る・切る・開くの状態遷移とアニメーションを優先する。
- 紙は内部的に `8 x 8` のパネルに分割して扱う。
- 見た目はなるべく1枚の折り紙に見えるよう、パネル間のワイヤーや説明オーバーレイは表示しない。
- 折りは固定順ではなく、ユーザーが `縦に折る` / `横に折る` を自由に選択できる。
- 縦折りは最大3回、横折りも最大3回。
- 切り抜きは赤いハートの別メッシュではなく、各パネルの `alphaMap` にハート型の穴を描く。
- `♥ cut` は連続カットモード。1度押した後は、紙をクリックするたびに複数回カットできる。
- 切る瞬間の上層ではハートは上向き。下の層では、折り重なりの向き差を `localQuaternion` として保存し、展開後に自然な向きになるようにする。
- 内部パネル境界でハートが欠けないよう、ハートの範囲にかかる周辺パネルにもカット情報を配る。
- `unfold` 後はプログレスバーで、折られた状態から開いた状態までスクラブできる。
- 背景は白、紙色は両面とも水色固定。
- 初期視点は真正面。ドラッグで視点変更、ホイールでズーム。

## 追加先

おすすめの追加先は以下です。

```text
prototype/origami-fold-cut-demo/
```

この zip の中身を、リポジトリルートから見て上記パスになるように配置してください。

## 起動方法

```bash
cd prototype/origami-fold-cut-demo
npm install
npm run dev
```

## 操作

- `縦に折る`: 縦方向の折り。最大3回。
- `横に折る`: 横方向の折り。最大3回。
- `♥ cut`: カットモード。押した後、紙をクリックするたびにハート穴を追加。
- `unfold`: すべて展開。表示されるプログレスバーで展開状態をスクラブ可能。
- `reset`: 初期化。
