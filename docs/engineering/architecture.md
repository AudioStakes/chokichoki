# Architecture

## 基本方針

見た目は3D、正確な計算は2Dで行う。

- 表示はThree.js / React Three Fiberを使う。
- 折る・ひらくアニメーションは軽めの3Dで表現する。
- 切り抜き位置、折り履歴、展開結果は元の正方形の2D座標系を基準に管理する。
- 3Dは見せ方であり、正確性の唯一の情報源にはしない。

## 技術方針

- Webアプリとして実装する。
- Reactを使う。
- 3D表示にはThree.js / React Three Fiberを使う。
- PWAとしてオフライン対応する。
- スマホ縦向き優先で設計する。

## 主要領域

### Product UI

- 状態に応じたボタン表示。
- 文字なしアイコンUI。
- 色パレット。
- 音ON/OFF。

### Origami Model

- 紙の2D座標。
- 折り履歴。
- 切り抜き一覧。
- 重なり順。
- 現在の遊び状態。

### Geometry

- 表示中の紙面へのタップ位置を元の紙座標へ変換する。
- 折りにより重なっている紙面を計算する。
- 切り抜きを全レイヤーへ適用する。
- ひらくときの鏡写し結果を計算する。

### Rendering

- 紙の3Dメッシュ。
- 折るアニメーション。
- ひらくアニメーション。
- 白い穴の表示。
- 表面と裏面の色。
- 影、厚み、層の見た目。

### Audio

- 操作ごとの短い効果音。
- 音ON/OFF状態。
- 初期ON。

## 重要な制約

- アニメーション中は状態変更を受け付けない。
- 3D表示の都合で紙を意図的にずらさない。
- 切り抜き位置の正確性を優先する。
- スマホでなめらかに動くことを優先する。
