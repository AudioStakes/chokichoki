# Interaction Rules

## 状態ごとの表示

### 初期状態

- 紙を表示する。
- 折るボタンを表示する。
- 図形ボタンは表示しない。
- ひらくボタンは表示しない。
- 新しい紙ボタンは表示しない。

### 折った後、まだ切っていない状態

- 折るボタンを表示する。
- 図形ボタンを表示する。
- ひらくボタンは表示しない。
- 最大3回折った場合、折るボタンは表示しない。

### 1個以上切った後

- 折るボタンを表示しない。
- 図形ボタンを表示する。
- ひらくボタンを表示する。

### 展開中

- すべての操作ボタンを表示しない。
- 紙タップも受け付けない。

### 完成後

- 新しい紙ボタンを表示する。
- 紙タップには反応しない。

## 操作制限

- 折る・ひらく・新しい紙のアニメーション中は操作を受け付けない。
- アニメーション中は押せないボタンを薄く表示せず、一時的に消す。
- 一度切った後は追加で折れない。
- 切った後も図形変更と追加切り抜きはできる。

## タップ判定

- 紙の少し外側までタップ判定を広げる。
- 紙の外側をタップした場合は、近くの紙の中へ自然に補正する。
- 補正されたことは見せない。
- 図形が紙の端からはみ出して切れることは許可する。

## 図形選択

- 図形ボタンは白い丸ボタンの中に濃いグレーの図形アイコンを置く。
- 選択中の図形ボタンは少し大きくする。
- 図形選択時に小さな「ぽん」音を鳴らす。

## 色変更

- 右上の虹色丸アイコンから色パレットを開く。
- 色パレットを開いている間、通常の操作ボタンは隠す。
- 色は赤、水色、黄、緑、ピンク。
- 色を選ぶと小さな音が鳴り、紙色が0.2〜0.4秒でふわっと変わる。
- 色を選ぶとパレットは閉じる。
- 紙のあたりをタップしてもパレットは閉じる。
- 色を変えても切り抜きは残る。
