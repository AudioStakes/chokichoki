# ADR 0003: 2D幾何モデルを正確性の基準にする

## Status

Accepted

## Context

見た目は3Dで折り紙を表示するが、切り抜いた位置や展開後の模様は正確である必要がある。3D表示だけを情報源にすると、折る・切る・ひらくの対応がズレる可能性がある。

## Decision

元の正方形の2D座標系を正確性の基準にする。折り履歴、切り抜き、展開結果は2D幾何モデルで管理し、3Dは表示手段として扱う。

## Consequences

- 切り抜き位置と展開結果を正確に扱える。
- 折り目に応じた反転・鏡写しを計算しやすい。
- Raycastingで取得した3Dタップ位置を2D座標へ変換する処理が必要になる。
- 表示とモデルの同期が重要になる。
